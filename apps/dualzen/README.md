# DualZen

Run pnpm install at the repository root.

From this app directory, configure app copy/assets/legal links, then run pnpm setup:expo, pnpm setup:firebase, and pnpm setup:sentry with the documented machine credentials. Configure RevenueCat and store listings separately. Run pnpm setup:ads only after choosing an ads policy, then regenerate native projects. No remote services have been provisioned.
