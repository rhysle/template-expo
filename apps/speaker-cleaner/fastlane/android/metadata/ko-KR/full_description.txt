휴대폰 스피커에 물이 들어갔나요? 스피커 물빼기·클리너가 안내형 클리어 웨이브 사운드로 안에 남은 물기를 밀어내고 가벼운 먼지나 이물질을 느슨하게 하는 데 도움을 줍니다. 30초 물빼기 후 내장 스피커 테스트로 결과를 확인하세요.

스피커 청소 및 테스트
• 안내형 물빼기: 3단계 클리닝 사운드로 스피커 안에 남은 물방울이 움직이도록 지원
• 선택 가능한 시간: 30초 Standard는 횟수 제한 없이 무료, Premium에서는 60초와 90초 제공
• Turbo 모드: 먹먹한 소리가 계속될 때 사용하는 더 강한 Premium 루틴
• 톤·주파수 발생기: 20~20,000 Hz 범위에서 정밀한 소리 생성
• 스테레오 테스트: 왼쪽, 오른쪽 또는 양쪽 채널을 따로 확인
• 간이 소음 측정기: 주변 소리의 실시간 최소·평균·최대 dB 표시
• 비공개 기록: Premium에서 청소 및 소리 측정 요약을 기기에 저장

하나의 앱에 담은 오디오 도구 4개
스피커 클리너, 물빼기, 주파수 발생기, 스테레오 테스트와 소음 측정기를 한곳에서 사용하세요. 마이크 샘플은 메모리에서만 처리되며 오디오를 녹음, 저장 또는 업로드하지 않습니다. 리포트와 기록은 기기에 남고 설정에서 삭제할 수 있습니다.

스피커에서 물 빼는 방법
1. 스피커를 가리는 케이스를 제거하고 스피커가 아래를 향하도록 기기를 놓으세요.
2. 이어폰이나 외부 스피커 연결을 해제하고 편안한 낮은 볼륨에서 시작하세요.
3. 안내형 클리닝 사이클을 실행하세요.
4. 스피커 테스트로 소리를 확인하고 여전히 먹먹하면 반복하세요.

음파는 휴대폰을 열지 않고 남은 물방울을 움직이거나 가벼운 먼지를 느슨하게 하는 데 도움을 줄 수 있지만, 손상된 하드웨어를 수리할 수는 없습니다.

무료 도구
30초 Standard 클리닝 무제한, 사인파 톤, 수동 스테레오 테스트, 최소·평균·최대값이 포함된 실시간 dB 추정치를 제공합니다.

PREMIUM 기능
60초·90초 사이클, Turbo 모드, 사각파·삼각파·톱니파, 자동 스테레오 테스트, 상세 소리 리포트, 기기 내 비공개 기록, 광고 없는 사용을 제공합니다.

이럴 때 사용하세요
• 물이 튄 뒤 소리가 먹먹하거나 작고 왜곡되어 들릴 때
• 소리로 스피커 안의 물기를 밀어내고 싶을 때
• 가벼운 먼지나 이물질로 음질이 흐려진 것 같을 때
• 왼쪽과 오른쪽 채널을 확인하고 싶을 때
• 주파수 발생기나 간이 소음 측정기가 필요할 때

개인정보 보호 우선
클리닝 사운드와 오디오 테스트는 기기에서 실행됩니다. 마이크는 주변 소리 크기를 실시간으로 추정할 때만 사용하며 샘플을 녹음, 저장 또는 업로드하지 않습니다.

주의사항
물기, 먼지 또는 이물질 제거를 보장하지 않습니다. dB 값은 추정치이며 보정된 전문 장비, 산업안전 장비 또는 의료 기기가 아닙니다. 스피커를 귀에서 멀리 두고 낮은 볼륨에서 시작하며, 불편하면 즉시 중지하세요. 액체에 심하게 노출되었거나 왜곡이 계속되면 전문 수리점에 문의하세요.

안내형 물빼기, 스테레오 확인, 기기 내 오디오 도구가 필요할 때 스피커 물빼기·클리너를 사용해 보세요.
